# Keyboard shortcuts

Keys act on the page in view and never while you are typing in a field.

## Flight screen (FLIGHT DATA)

| Key | |
|-----|---|
| **M** | Satellite imagery on / off (schematic chart) |
| **L** | Realistic sunlight on / off |
| **T** | Horizon lock (first-person view keeps the horizon level) |
| **P** | Predicted trajectory corridor |
| **Arrow keys** (hold) | Look around in the first-person view: up / down ±90°, left / right ±110°; release to return to the nose |

| Mouse | |
|-------|---|
| Drag / wheel on the 3D view | Orbit and zoom the chase view (3P), 50 m to 2.5 km |
| Hover the mini-map | Enlarge it |
| Click the mini-map | Swap it with the 3D view; click the 3D view to swap back |
| Click an annunciator | Silence it until the next connection |
| Top edge of the window | Show the minimise / maximise / close buttons; drag to move the window |
| ▶ on the right edge | Open / close the [side panel](side-panel.md) |
| **Enter** in the SPD field | Send the target speed |

## Mission planner (FLIGHT PLAN)

| Key | |
|-----|---|
| **V** | Select |
| **W** | Waypoint |
| **C** | Circle |
| **P** | Perimeter |
| **A** | Area scan |
| **K** | Corridor |
| **I** | Point of interest |
| **L** | Landing |
| **O** | Operator (ground antenna for the radio link) |
| **Enter** | Finish the polygon or line being drawn |
| **Esc** | Cancel the drawing, go back to select, or deselect |
| **Delete** / **Backspace** | Delete the selected segment |
| **Ctrl + Z** | Undo |
| **Ctrl + Y**, **Ctrl + Shift + Z** | Redo |

| Mouse | |
|-------|---|
| Drag a point / mid-point handle / centre handle / rim handle | Move a vertex / insert a vertex / move the whole shape / change a circle's radius |
| Drag the **H** or antenna marker | Move the take-off point / the operator |
| Right-click | Context menu: add a waypoint or POI here, take-off point here, operator here, insert or delete a vertex, delete a segment |
| Drag a segment card by its title | Change the flight order |
| Hover a red photo dot | Show the photo's ground footprint |
| Hover the elevation profile | Show that point on the map |
