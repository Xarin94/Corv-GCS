HGT elevation conversion now runs in the terrain worker, keeping the UI responsive while large terrain files are prepared. Terrain, camera and Livox data now have a shared rendering contract that can support additional graphics backends. Joystick controls now include eight configurable RC inputs, two servo button commands and FPV look buttons.

- **Eight RC inputs:** map physical axes or analog buttons/triggers to CH1–18, including on controllers with only four physical axes. Existing mappings are preserved; input previews work with override disabled.
- **Servo buttons:** two configurable button/output/position assignments, with a 0–100% range (1000–2000 µs). Each press sends one command. A separate session-only switch enables servo commands independently of RC override; held buttons do not retrigger after reconnect or focus changes.
- **FPV look buttons:** map up, down, left and right to the same first-person camera movement as the arrow keys, including diagonals and return to center on release. Works in demo and with RC override disabled.
- **RC fixes:** correct ArduPilot RC_OPTIONS override bit, correct release values for channels 9–18, and controller deselection/reconnection handling. Joystick configuration is saved automatically.
- **Terrain loading:** one preparation job per tile, acknowledgement before chunk generation, and recovery when the worker cannot start or fails. SRTM1/SRTM3 signed elevations and void samples are preserved.
- **3D resolution profiles:** Native, Balanced and Eco in SYS CONFIG, with a separate resolution limit for the 3D canvas. HUD and interface text retain the display resolution.
- **Rendering architecture:** backend-independent terrain, camera and point-cloud models; Three adapters own GPU resources. Terrain LOD changes preserve satellite textures, and Livox uploads only changed buffer ranges.
- **Diagnostics:** cumulative counts across rendering passes, CPU submission timing and a reproducible visible-window measurement command for developers.
- **Qt evaluation:** a separate Qt Quick 3D prototype reads versioned binary snapshots of the same terrain, camera and LiDAR data. The distributed GCS uses **Three.js/WebGL2**; the Qt prototype is excluded from installers.

Validation: HGT worker/fallback tests, rendering backend tests, data-contract and GPU-adapter tests, Python/JavaScript packet compatibility tests, joystick logic tests and Electron joystick UI tests all pass. Joystick tests use a simulated controller and MAVLink transport; physical servo operation has not been tested.

Installers: Windows x64, macOS Apple silicon and Intel, Linux AppImage and Debian/Ubuntu package. This updated v1.8.1 replaces the earlier installers under the same release tag.
